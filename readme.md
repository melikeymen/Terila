# Terila

A Minecraft server implementation in C++23.

## Build

Requires CMake 3.20+ and a C++23 compiler.

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

## Run

```bash
./build/Release/terila.exe
```

Requires an `input/` folder next to the executable (or in a parent directory). Listens on `0.0.0.0:25565`.

## Minecraft versions

The tree carries the supported protocol releases side by side and compiles one of them:

```bash
cmake -B build -DTERILA_MC_TARGET=26.3
```

26.3 is the floor; older releases are refused at compile time. Release-specific behaviour is
kept behind `TERILA_HAS_*` flags instead of version comparisons, so adding a release means
appending one row and one block of differences — see `src/version/README.md`.

## Logging

7 levels (FATAL, CRITICAL, ERROR, WARN, INFO, DEBUG, TRACE), 8 scopes. Set `cfg.min_level` in `main.cpp` (default: `INFO`).

- Production: `INFO` and above
- Development: `DEBUG`
- Byte-level debugging: `TRACE`

```cpp
LOG_INFO(Network, "new connection");
LOG_WARN(Protocol, "read_varint: exceeds max 5 bytes (protocol violation)");
LOG_ERROR(Network, "write failed: {}", error.message());
LOG_FATAL(Main, "input/ not found. cwd={}", fs::current_path().string());
```

## Data source

Registry, tag, recipe, loot, advancement and command-tree data are loaded from `input/`, generated by the Terila data extractor. The extractor is not yet publicly released; `input/` is gitignored.
